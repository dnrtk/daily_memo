# ロードマップ

## Phase 1(完了)

エディタ・ファイルツリー・カテゴリ管理・クイックメモ・LLM 接続設定。

## Phase 2: 自然言語検索(完了)

```
[notify でフォルダ監視] → [サイズ・時刻 → blake3 で差分検出] → [抽出] → [チャンク分割]
      → SQLite: FTS5(文字バイグラム) + sqlite-vec(Ollama /api/embed の埋め込み)
検索: [LLM がクエリを解釈: 本題・語・種類・期間・カテゴリ] → BM25 とベクトルを RRF で統合 → ファイル単位に集約
```

- 抽出: md(見出し単位)/ txt / csv(ヘッダ付きブロック)/ html / docx(見出しスタイル、日本語版 Word の数字 styleId にも対応)/ xlsx・xls・ods(シートと行)/ pptx(表示順、ノート込み)/ pdf(PDFium、ページ単位)
- 見出しだけのまとまりは次の節にまとめ、見出しだけのチャンクを作らない
- 埋め込みサーバーが落ちていても全文検索は使える。待ちのベクトルは 1 分ごとに再試行
- 埋め込みモデル名と次元を記録し、変わったら「作り直す」でベクトルだけ再作成
- ライセンス画面(cargo-about + npm + PDFium 同梱 LICENSE を全文 HTML 化)

既知の制約:

- PDF・Office は既定のアプリで開くだけで、該当ページ / スライドへのジャンプはできない(場所はトースト表示)
- スキャン画像だけの PDF(文字情報なし)は読めない。OCR は未対応
- 期間指定はファイルの更新日時で絞る。日次ノートの日付(ファイル名)とはずれることがある

## Phase 3: LLM による保存先振り分け(次)

- クイックメモに「自動」を追加
- 1 段目: メモ本文の埋め込みと各カテゴリの `description` + `examples` の埋め込みのコサイン類似度で判定。差が十分なら即決
- 2 段目: 曖昧なときだけ LLM にカテゴリ定義一覧を渡し、JSON(カテゴリ ID・タイトル・タグ)で返させる(`llm::chat_json` は実装済み)
- 決定後は `Workspace::save_to_category` を呼ぶだけ(実装済み)
- 誤振り分けを手で直した履歴を `examples` 候補として提案
